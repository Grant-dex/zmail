# DeepSeek 官方技术报告阅读索引

收录范围：DeepSeek-V3、DeepSeek-R1 的原始技术报告与官方仓库。以下为中文阅读摘要，不是官方译文；不覆盖后续所有模型版本。

## DeepSeek-V3 Technical Report

- 作者：DeepSeek-AI。
- [论文页面](https://arxiv.org/abs/2412.19437) · [PDF](https://arxiv.org/pdf/2412.19437)
- [官方仓库与说明](https://github.com/deepseek-ai/DeepSeek-V3)

### 中文摘要

DeepSeek-V3 研究如何以较高效率训练大型混合专家（MoE）语言模型。主模型总参数量为 6710 亿，每个 token 激活约 370 亿参数，预训练数据规模为 14.8 万亿 token。其架构结合多头潜在注意力（MLA）和 DeepSeekMoE，并引入无辅助损失的负载均衡策略，以减少专家负载均衡对模型表现的影响。

训练方面，报告介绍 FP8 混合精度训练及计算与通信协同优化；多 token 预测（MTP）既作为训练目标改善模型能力，也可用于推测解码。预训练后，模型通过监督微调与强化学习进一步提升表现，并从推理模型中蒸馏部分推理能力。

### 阅读重点

1. MLA 与 MoE 如何分别影响注意力缓存及每个 token 的计算成本。
2. 无辅助损失负载均衡策略如何分配专家负载。
3. MTP 的训练作用与推理加速用途有何区别。
4. FP8 训练与跨节点通信优化如何配合。

以上参数与训练描述来自官方仓库介绍。每个 token 的激活参数量不等于完整部署的显存需求，具体部署需参考官方推理说明。

## DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

- 作者：DeepSeek-AI。
- [论文页面](https://arxiv.org/abs/2501.12948) · [PDF](https://arxiv.org/pdf/2501.12948)
- [官方仓库与说明](https://github.com/deepseek-ai/DeepSeek-R1)

### 中文摘要

DeepSeek-R1 系列探索通过强化学习提升语言模型推理能力。DeepSeek-R1-Zero 在基础模型上直接进行大规模强化学习，不以前置监督微调作为起点，展示出自我验证、反思和较长推理链等行为，同时也存在可读性较差和语言混杂等问题。

DeepSeek-R1 在强化学习前加入冷启动数据，并采用包含两阶段监督微调和两阶段强化学习的训练流程，在推理能力与输出可用性之间取得更好的平衡。R1 与 R1-Zero 基于 DeepSeek-V3-Base 训练。

官方还发布了基于 Qwen 和 Llama 的蒸馏模型，使用 R1 生成的样本对较小的稠密模型进行微调，规模覆盖 1.5B、7B、8B、14B、32B 和 70B。这为研究推理能力如何迁移到较小模型提供了参考。

### 阅读重点

1. 区分 R1-Zero 的探索实验与 R1 的多阶段训练流程。
2. 冷启动数据如何改善输出可读性及训练起点。
3. 强化学习与蒸馏分别在哪个阶段发挥作用。
4. 评测时同时核对模型版本、采样配置和输出长度限制。

## 建议阅读顺序

先阅读 V3，理解基础架构和训练效率；再阅读 R1，理解推理强化学习与蒸馏。两者分别侧重基础模型训练和推理能力训练。
